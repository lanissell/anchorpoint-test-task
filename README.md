# Anchorpoint — тестовое задание (Unity-разработчик)

3D-бродилка от первого лица с системой случайных событий. У игрока есть база, вокруг которой он исследует локацию. Во время игры периодически возникают случайные события двух типов: на базе и во время исследования мира.

- **Движок:** Unity 6000.3.11f1
- **Сцена:** `Assets/Scenes/GameScene.unity`

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `WASD` / стрелки |
| Осмотр (камера) | мышь |
| Бег | `Left Shift` |
| Прыжок | `Space` |
| Дальняя атака (выстрел) | `ЛКМ` |
| Ближняя атака | `V` |
| Подобрать предмет | `E` |

Подбор ресурса — по кнопке `E`: подбирается ближайший предмет в радиусе досягаемости.

## Как реализованы механики

### Архитектура

Проект разделён на три слоя:

- **Core** — доменные абстракции (юниты, компоненты, события, интерфейсы).
- **App** — конкретные реализации событий, компонентов юнитов, брейнов.
- **Infrastructure** — сервисы, ввод, UI, окружение.

Зависимости разрешаются через `ServiceLocator` (`AppLoader.ServiceResolver`).

### Юниты — композиция из компонентов

Юнит (`Unit`) — это контейнер компонентов. Способность юнита определяется **набором компонентов**, которые на нём висят:

- `MovementComponent`, `LookComponent`, `JumpComponent`, `GravityComponent` — перемещение.
- `HealthComponent` — здоровье/смерть.
- `RangedAttackComponent`, `MeleeAttackComponent` — атака.
- `NavigationComponent` — навигация NavMesh (враги идут к игроку).
- `InteractorComponent` — подбор предметов.
- Брейны: `PlayerBrainComponent` (читает ввод), `EnemyBrainComponent` (ведёт к цели).

Игрок и враги собираются из одних и тех же кирпичей через `UnitDefinition` (ScriptableObject) + `UnitInstaller`. Новый тип юнита = новая комбинация компонентов в данных + "мозг", которые определяет последовательность вызова компонентов.

### Базовая система событий

`EventService` — ядро системы:

- Хранит список доступных событий в ассете `EventCatalog` (`Assets/Configs/EventCatalog.asset`).
- Периодически выбирает случайное событие через интервал `N = Random.Range(MinInterval, MaxInterval)` секунд. `MinInterval` (A) и `MaxInterval` (B) настраиваются в ассете каталога.
- Учитывает контекст игрока: на базе (`OnBase`) или вне базы (`Exploring`). Фильтрует кандидатов по текущему контексту перед выбором.

Контекст переключается зоной `BaseZone` (триггер-коллайдер на базе): вход/выход игрока обновляют `PlayerContextService`.

События **data-driven**: каталог хранит список конфигов через `[SerializeReference, SubclassSelector]`. Чтобы добавить событие, не нужно править enum/switch — достаточно добавить конфиг в каталог. Каждый конфиг (`GameEventConfigBase`) хранит контекст, стартовое сообщение, сообщения успеха/провала и метод `Build()`, создающий рантайм-событие (`IGameEvent`) с жизненным циклом `Begin → Tick → Cleanup`.

### Реализованные события (4)

Все настроены в `EventCatalog.asset`:

1. **Пожар** (на базе) — спавнит объекты «огонь» (`Fire`-юниты) на базе. Через настраиваемое время исчезают. Игрок может потушить.
2. **Атака врагов** (на базе) — спавн 2–3 NPC, которые двигаются к игроку (NavMesh). Через настраиваемое время `lifetime` исчезают.
3. **Засада** (исследование) — спавн одного NPC недалеко от игрока, работает по логике атаки. Реализована как тот же `EnemyAttackEventConfig` с `count = 1` и контекстом `Exploring`.
4. **Находка ресурсов** (исследование) — недалеко от игрока появляется случайный предмет из набора (`prefabs`). Игрок подбирает его кнопкой `E` за отведённое время. В уведомлении показываются координаты находки.

Числа (количество NPC, время жизни события, дистанция спавна, таймаут подбора) настраиваются извне — в полях каждого конфига каталога.

### UI-фидбек

`NotificationService` + `NotificationController`/`NotificationView`:

- При возникновении/завершении события на экран выводится текстовое уведомление («На базу напали!», «Вы подобрали ресурсы» и т.д.).
- Каждое уведомление висит `Duration` (X) секунд, затем исчезает.
- На экране максимум `MaxCount` (K) уведомлений — оба параметра настраиваются в `NotificationView`.
- Уведомления формируют список, новые добавляются **сверху** (`Insert(0)`), при переполнении удаляются самые старые снизу.

### Сцена

- Локация — завод из бесплатных ассетов.
- Управляемый игрок от первого лица.
- Зона «база» (`BaseZone`) — на ней срабатывают события базы; вне неё — события исследования.
- Пулинг объектов (`PoolService`) для NPC, эффектов, звуков, декалей.
